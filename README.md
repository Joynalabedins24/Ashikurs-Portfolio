# 🎨 Ashikur Portfolio

A modern and responsive personal portfolio website for a UI/UX and Graphic Designer, built with HTML5 and CSS3.

## 🌐 Project Overview

This portfolio presents a designer/developer profile with:

- 👋 Hero / Introduction
- 👤 About Me
- ✨ Features
- 🎨 Branding
- 💻 Services
- 📊 Project & Client Statistics
- 🔗 Social Media Links
- 📄 CV Download
- 📱 Responsive Layout

## 📱 Responsive Design

Separate stylesheets are used for desktop, tablet and mobile layouts:

```html
<link rel="stylesheet" href="css/style.css" />
<link rel="stylesheet" href="css/style-tab.css" />
<link rel="stylesheet" href="css/style-mobile.css" />
```

The responsive CSS adjusts feature cards, branding layout, service layout, spacing and text alignment for smaller screens.

## 💻 How to Run

No package installation is required.

### Clone the repository

```bash
git clone https://github.com/Joynalabedins24/Ashikurs-Portfolio.git
```

### Open the project

```bash
cd Ashikurs-Portfolio
```

Then open `index.html` in your browser.

For development, **Visual Studio Code + Live Server** can be used.
